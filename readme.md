# 💻 Clone da Página do MacBook Air

Projeto desenvolvido durante a **Start Week**, com o objetivo de colocar em prática habilidades de **HTML**, **CSS** e **JavaScript Vanilla**, recriando a interface da página oficial do **MacBook Air** da Apple.  
Uma experiência focada em design moderno, interatividade e responsividade.

## 🧠 O que foi aprendido nesse projeto

### ✅ Uso de variáveis CSS (custom properties)

Aprendi como tornar o CSS mais limpo e reutilizável usando variáveis para cores, fontes e espaçamentos. Isso ajuda a manter o projeto consistente e fácil de atualizar.

### 🖱️ Manipulação da página com eventos de clique

Utilizei JavaScript para tornar a página interativa, como trocar as imagens dos modelos do MacBook com base na cor selecionada pelo usuário. Isso é feito manipulando elementos diretamente na estrutura da página.

### 🧱 Organização modular dos componentes

Organizei os estilos e scripts por seção e função, facilitando tanto a leitura quanto futuras manutenções ou melhorias.

### 🚀 Publicação com GitHub Pages

Ao final do projeto, coloquei a página no ar utilizando o **GitHub Pages**, uma ferramenta gratuita para hospedar sites direto do repositório. Assim, qualquer pessoa pode acessar o resultado final pela internet.
